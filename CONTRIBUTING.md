# Contributing

Thanks for helping improve Engram.

1. Open an issue before large behavioral or data-model changes.
2. Do not include real agent transcripts, repository data, credentials, or
   SQLite databases in issues, fixtures, commits, or pull requests.
3. Install with `pnpm install --frozen-lockfile`.
4. Run `pnpm verify` and `pnpm build` before submitting a pull request.
5. Add tests for persistence, deletion, security, or protocol changes.

By contributing, you agree that your contribution is licensed under the MIT
License included in this repository.
